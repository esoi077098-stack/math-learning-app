# Math Quest

A simple, friendly math learning app built with HTML, CSS, and JavaScript.

## Features
- Practice questions across addition, subtraction, multiplication, and division
- Difficulty modes: Easy, Medium, Hard
- Score, streak, and level tracking
- Quick learning tips for each topic
- Works fully in the browser with no install required

## Run locally
Open `index.html` in a browser.

If you want to serve it locally:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000

## Project structure
- `index.html` – app layout
- `styles.css` – visual design and responsive layout
- `app.js` – math generation, scoring, and game logic
